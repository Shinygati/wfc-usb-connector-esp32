Open a Wi-Fi game's Nintendo WFC Settings › Nintendo Wi-Fi Connection Settings › pick an empty slot › Nintendo Wi-Fi USB Connector. Your ESP32 answers as that connector.

Hardware

Your ESP32 boards, their radio firmware, and the original USB Connector.

ESP32 boards
Radio firmware
Install or update the radio firmware on the selected ESP32. The chip is detected automatically.
Plug into the board's UART/COM port. If it can't connect, put it in download mode by hand (hold BOOT, press and release RESET, release BOOT) and click Install firmware again.
Original Nintendo Wi-Fi USB Connector
Not plugged in
Needs the WinUSB driver once: in Zadig, pick the device with USB ID 0411 008B and install WinUSB. On Linux, run once as root or add a udev rule for 0411:008b.
